Esta es una calculadora escalable, la cual sigue en funcionamiento una vez ejecutada hasta que el usuario decida salir del proceso.
Para empezar, primero debe escoger la operación que desea realizar en el momento (nota: una vez iniciada esa operacion debe terminar el proceso para elegir otra)
Luego introduzca los numeros que buscas calcular (el programa le preguntara si desea ingresar mas de 2 numeros)
Al seleccionar la opción de ver el calculo, se mostrara el resultado y los números que utilizó
y ya.
